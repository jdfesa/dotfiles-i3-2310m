# dotfiles-i3-2310m

Dotfiles, scripts, and configuration for a **Positivo BGH A470 (2011)** running
Debian 13 with i3 on Xorg.

**Hardware:** Intel Core i3-2310M · Intel HD 3000 · 8 GB RAM · 120 GB SATA SSD.
