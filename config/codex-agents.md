# Laptop defaults

- Application lightness and low CPU usage are the main priority on this Debian
  13 laptop (i3-2310M, Sandy Bridge, 8 GB RAM, SATA SSD). Choose the lightest
  adequate compatible tools above aesthetics, convenience or feature count.
  Prefer console/TUI alternatives when they really reduce CPU work. Avoid
  unnecessary daemons, watchers, effects and compiling large toolchains locally.
  Justify heavier alternatives and do not claim gains without measurements.
- Preserve security, authenticated sudo, SSH recovery and the existing user
  session. Ask before installing unrelated stacks or changing system/network
  services. Do not close unrelated windows or restart the machine for setup.
- Keep visible application/system/help text in English. Conversation and
  documentation may be Spanish, with English filenames.
- Never save credentials, session tokens, private keys, Wi-Fi secrets, raw
  histories, memory databases or private backups in a configuration repository.
- Engram belongs to this machine and its projects. Do not import other machines'
  memories or enable cloud synchronization without explicit approval.
